# Archiver components

- `encoder.py` — упаковка директории в ZIP, Base64 в один TXT.
- `decoder.py` — обратная операция, SHA-256 и безопасная проверка путей при распаковке.
- `collector.js` — собирает `.MessageText` из последнего `.ConvoStack__content` в текущем DOM и скачивает общий TXT.

В основной реализации нет собственного VKT1, нумерации чанков или HTML-приёмника. Проверка протокола описана в корневом README.
