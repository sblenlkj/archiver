# Demo datasets

- `basic/` — небольшой учебный пример Python.
- `cars/` — `cars.py` с классами `Engine`, `Car`, `Transmission`, `Wheel`, `Garage`.

Оба набора кодируются одновременно командой `python3 -m archiver.encoder demo --output encoded.txt` (при установленном пакете) или через `PYTHONPATH=src`.
